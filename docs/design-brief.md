# Design brief

Use a quiet, utilitarian owner workspace. Put the current task and state first, keep destructive archive deletion visually distinct, and state exactly when data will be sent to configured providers.

Accessibility requirements:

- semantic labels for every control;
- keyboard-operable navigation and actions;
- visible focus;
- status changes announced through `aria-live`;
- no color-only state;
- readable message bodies without executing markup;
- confirmation language that names the complete archive and irreversibility.

Security copy must use concrete language: processing consent, rejected secret categories, encrypted archive, full export, and permanent whole-session deletion.
