### Checklist Field Contract

Every checklist row contains `Check ID`, `Check`, `Severity`, `Release Effect`, `Applicability`, `Source`, `Evidence` and `Rationale`. Severity and release effect are separate. P0 and P1 are blocking; P2 is blocking only for a required gate, primary/critical journey, applicable accessibility/security/privacy/data-integrity requirement, supported client/viewport or material design/interaction meaning. Otherwise P2 and P3 are advisory.

Evidence must be recorded using the eval result format from `docs/dod-evals.md`: `eval_id`, `gate`, `scope`, `level`, `status`, `source_references`, `environment_fingerprint`, `owner`, timestamps, `expected`, `actual`, `evidence_references`, `evidence_limit`, `findings` and `rerun_of` when applicable.

### Current Execution Limitations

Це межі доказів на 05.09.2026, не вимоги й не live-діагностика.

1. Поточна архітектура вже посилається на реалізацію Node/Settings/session/MySQL, Rust workspace, lockfile та CI. Твердження «код не існує» або «немає жодного logout/rotation» вилучені. Наявність коду чи старого локального тесту не є актуальним deployed pass.
2. Google-only контракт потребує завершення реалізації та свіжих інтеграційних і same-tab browser доказів. Поточний запуск лише узгодив визначення QA; він не перевіряв live login.
3. Production Rust/store continuity, Node supervision/NDJSON, Matrix room/device/outbox, provider/runtime/catalog, MySQL/archive й повні шляхи Власника потребують точних release-configuration доказів. Наявні історичні feasibility/local артефакти не агрегуються автоматично в release pass.
4. Baseline залишається незмінним. Поточний render-binding охоплює зовнішні залежності, але історичну неперервність root bytes від первинного схвалення не доведено; не створено нового схвалення чи visual pass.
5. MFA-виняток уже визначений PRD. Його компенсувальні вимоги лишаються обов'язковими; повна ASVS Level 2 відповідність не заявляється.
6. Поточні browser/native-client accessibility, H1–H10 і спостереження за завданнями Власника в цьому запуску не виконувалися.
