# Matrix.org: зробіть це зараз

**Сервер купувати не потрібно.** Для V1 використовуємо безкоштовний `matrix.org`.

## Крок 1. Встановіть Element на Mac

1. Відкрийте [пряме завантаження Element для Mac](https://packages.element.io/desktop/install/macos/Element.dmg).
2. Відкрийте завантажений файл `Element.dmg`.
3. Перетягніть Element у папку `Applications`.
4. Відкрийте Element.

**Має бути:** вікно входу або створення акаунта.

**Далі:** крок 2.

## Крок 2. Створіть свій Matrix-акаунт

1. Натисніть **Create account**.
2. На екрані вибору сервера знайдіть `matrix.org`.
3. Якщо його немає: натисніть **Edit** → введіть `matrix.org` → підтвердьте.
4. Введіть бажане ім'я користувача.
5. Якщо воно зайняте — змініть його та продовжте.
6. Створіть сильний пароль і збережіть його в менеджері паролів.
7. Завершіть перевірку email або CAPTCHA, якщо Element попросить.

**Має бути:** ви бачите свій Matrix ID на кшталт `@your-name:matrix.org`.

**Далі:** крок 3.

## Крок 3. Увімкніть відновлення ключів

1. У Element відкрийте **Settings**.
2. Відкрийте розділ **Security & Privacy** або **Encryption**.
3. Увімкніть **Secure Backup** / **Recovery**.
4. Збережіть recovery key у менеджері паролів.

**Не робіть:** не надсилайте recovery key, пароль, API key або OAuth token мені, у Matrix-чат чи в репозиторій.

**Має бути:** Element показує, що backup/recovery увімкнено.

**Далі:** крок 4.

## Крок 4. Перевірте Mac-пристрій

1. У тому самому розділі безпеки відкрийте **Sessions** / **Devices**.
2. Переконайтеся, що поточний Mac позначено як trusted або verified.

**Має бути:** один перевірений пристрій — ваш Mac.

**Далі:** зупиніться тут і напишіть мені: `Matrix готово`.

## Не робіть нічого з цього

- Не купуйте Matrix-сервер, VPS або hosting.
- Не створюйте кімнату вручну.
- Не створюйте бота вручну.
- Не налаштовуйте DNS, SSH або Cloudflare для Matrix.

Після повідомлення `Matrix готово` наступним кроком буде підключення бота й створення однієї приватної E2EE-кімнати. Я дам його так само: з конкретним посиланням, кнопками й очікуваним результатом.
