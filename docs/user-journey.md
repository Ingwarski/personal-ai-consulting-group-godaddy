# User journey

1. The owner opens the application and signs in with the configured Google account.
2. The application establishes a secure owner session and redirects to the protected workspace.
3. The owner can connect subscription runtimes and refresh the capability catalog.
4. The owner selects supported models and a speed preset in Settings.
5. The owner reviews or edits the four Markdown instruction documents. Saving creates a new encrypted revision.
6. On the Consultation page, the owner enters a request and explicitly consents to processing.
7. The application validates content, acquires database-scoped leadership, pins settings and instructions, and starts the canonical session.
8. Intake selects a direct answer, one clarification, or a consilium. Confirmed messages appear in order.
9. The owner may stop active work. The application fences further output and preserves an encrypted partial archive where possible.
10. Successful work commits the encrypted archive before closing the session.
11. The owner may export the full archive to the browser or permanently delete the complete archive after an explicit confirmation.
12. The owner signs out from the current browser or revokes all application sessions.
