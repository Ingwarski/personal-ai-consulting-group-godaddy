# Product idea

Personal Consultant gives one authenticated owner a private browser workspace for business consulting and coaching. A short request can receive a direct answer. A consequential or multi-domain request can invoke a Head Consultant, selected specialists, and a Critic, with confirmed messages presented in canonical order.

The owner controls model selection, speed, editable operating instructions, session stop, archive export, and archive deletion. The application rejects secret-like input, requires explicit processing consent, and keeps provider credentials separate from owner authentication.

Success means the owner can complete a consultation from the browser, recover safely after process interruption, inspect the confirmed result, and manage the encrypted whole-session record without exposing plaintext through persistent application state.

The current host is the existing GoDaddy Node.js 22 application with MySQL. Extracting that composition root is a later architectural migration.
