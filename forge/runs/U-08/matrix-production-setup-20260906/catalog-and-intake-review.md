## Виявлене відхилення та ремонт

Поточний intake prompt описував консиліум для складних міждисциплінарних задач, але не переносив `FR-008` / PRD §3.2 для явно запитаної незалежної критики. Формулювання про заборону зміни ролей також не відділяло допустимий вибір режиму від підміни повноважень. Фактичний результат — direct попри прохання reviewed by the Critic.

В `src/runtime/consultation-intake.ts` уточнено семантичний вибір: незалежна критика або явно запитаний консиліум вимагають consilium навіть для короткої відповіді. Додано обов'язковий boolean `independentReviewRequested`; сервер відхиляє суперечність true + direct, відсутність або неправильний тип поля. Clarification може попросити відсутній критичний факт перед критикою. Ролі, кількість спеціалістів, провайдери, права та налаштування незмінні. Це не маршрутизація за regex-ключовими словами.

Межа доказу: сервер перевіряє узгодженість структурованого рішення, але не може сам гарантувати правильність семантичної класифікації моделі. Потрібна фактична перевірка опублікованої версії; її результат не підмінюється тестовими фікстурами.
