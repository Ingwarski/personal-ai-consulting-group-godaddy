Операційний дозвіл — повідомлення користувача `go ahead - work efficient and fast! I need to show the prototype in one hour!` після пояснення несправності. ## Пропущені права кешу медіа, 2026-09-07T11:38:06Z

Після публікації `1c790377beff271abe5061de1f13face46bc23f9` Chrome Published показав: етап `store`, фіксована мітка `other`, права `644`, звичайний файл належить поточному власнику, одне посилання, не symlink. Вміст не читався. Це підтверджує причину перевірки прав, але ще не встановлює конкретне ім'я живого файлу.

Перевірено локальні джерела зафіксованих `matrix-sdk`/`matrix-sdk-sqlite` 0.18.0: `client/builder/mod.rs::build_store_config` створює також `SqliteMediaStore`, а `media_store.rs` визначає `matrix-sdk-media.sqlite3`. Наш `secure_fresh_store_files` охоплював state, crypto й event-cache, але пропустив media та її WAL/SHM. Із поточною маскою процесу новий SDK-файл може лишитися 0644; це джерельно підтверджений пропуск, конкретний живий файл перевіряється після розширення фіксованих діагностичних міток.

Додано окрему owner/CSRF-дію лише для цих трьох файлів і лише після точного діагностичного результату `store`/media/0644/current-owner/regular/single-link. Дія не запускається автоматично з `prepare`, недоступна Preview чи активному процесу. До зміни перевіряє pinned release, приватні каталоги, обидві встановлені програми, наявний приватний binding і весь store/spool. Невідомий небезпечний об'єкт блокує зміни. Файли відкриваються без слідування symlink, повторно перевіряються inode/owner/link/mode/parent; лише 0644 звужується до 0600 через дескриптор. Байти не читаються й не записуються; після дії повторно перевіряються розмір, mtime, inode та повна сувора інспекція.

Для майбутніх файлів синхронний spawn setup і production sidecar успадковує попередню маску, посилену `0077`; Node повертає свою попередню маску до виходу з синхронного виклику. Пороги довіри, HTTP-приватність, фіксований Rust-пакет та наявний пристрій збережені. 786 тестів пройдено під Node 22.23.2, включно з реальним дочірнім процесом без облікових даних, збереженням байтів/inode та відмовою на links/чужих режимах/небезпечних каталогах/відсутньому binding. Build, typecheck й environment policy пройдені. Публікація й окрема жива дія ще очікуються на момент запису.
