# Відновлення після завершення сеансу Matrix

Зафіксовано 2026-09-07T11:18:23Z. Користувач повідомив, що підтвердження спочатку в Safari, потім у Chrome завершилося помилкою Element. На Published через Chrome повторно спостерігався `matrix_setup_unavailable`, але сторінка продовжувала показувати попереднє порівняння й кнопку підтвердження. Помилка Element вже не була відкрита під час огляду; її точний текст не відтворюється як спостережений факт.

Код має незмінний 15-хвилинний строк процесу Node/Rust і п'ятихвилинний строк окремого SAS. Нове порівняння не поновлює строк процесу. Час спостережень узгоджується із завершенням процесу за таймером, але попередній код не зберіг точну причину його завершення. Підтверджений дефект: обробник помилки зберігав старий `view.status`, отже показував недійсне порівняння як чинне.

Вузьке виправлення Node:

- завершений/недоступний процес закривається; старі SAS-дані вилучаються зі сторінки, успішне закриття дає стан `stopped`;
- невдале закриття не дозволяє новий запуск, стан лишається `stopping`;
- `stale_comparison` прибирає лише недійсне порівняння, зберігаючи список пристроїв;
- нове порівняння не надсилається, якщо залишилося менш як шість хвилин: п'ять хвилин SAS плюс хвилина на початок обміну;
- сторінка пояснює спільний ліміт і показує приблизний залишок на момент її оновлення; помилки скеровують до відновлення наявного сховища, не створення заміни.

Ні 15-хвилинний ліміт, ні ручне підтвердження довіри, ні перевірки приватності не вимкнено. Rust, секрети, ключі, пристрої, повідомлення, схеми БД та stateless Preview не змінено. Операційний дозвіл — повідомлення користувача `go ahead - work efficient and fast! I need to show the prototype in one hour!` після пояснення несправності. Це не дозвіл оголосити незавершений продукт готовим.

Перевірка: 19 цільових тестів пройдено; повний `npm run check` під Node 24.16.0 і цільовим Node 22.23.2 — 774 тести, build, typecheck й environment policy пройдено на обох. Усі 29 вхідних файлів збірки Rust збігаються з SHA-256 наявного незмінного пакета; перебудова не потрібна. SDD `--before implementation` перевірив 13 документів без помилок. Публікація ще очікується на момент цього запису. Живе підтвердження довіри та доставлена консультація ще не доведені.
