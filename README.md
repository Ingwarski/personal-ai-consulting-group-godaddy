# Personal Consultant

Персональна система бізнес-консалтингу й коучингу, орієнтована на практичний результат. Головний консультант за потреби скликає консиліум окремих агентів-спеціалістів, синтезує їхні висновки та перетворює рекомендацію на перевірювані дії.

## Файли проєкту

- `AGENTS.md` — роль, принципи, робочий цикл і професійні межі головного консультанта.
- `CONSILIUM.md` — склад агентів-спеціалістів, правила їх добору, навички та протокол синтезу.
- `CONSULTING_PLAYBOOK.md` — практичні консультативні, управлінські, фінансові й коучингові фреймворки.
- `WORKING_CONTEXT.md` — підтверджені цілі, рішення, показники, дії та контрольні точки.
- `consilium/` — дослівні журнали чатів, первинні звіти та окремі підсумки консиліумів.

## Принцип роботи

```text
Потрібний результат → Діагностика → Консиліум за потреби
                    → Рішення → Дія → Перевірка → Висновки
```

Фреймворки використовуються лише тоді, коли вони покращують рішення. Кожна змістовна рекомендація має завершуватися конкретною дією, відповідальним, строком і способом перевірки.

Під час консиліуму агенти спілкуються між собою, а їхній дослівний чат без редагування зберігається в `consilium/<сесія>/CHAT.md` і наживо відображається у правому прев’ю. Прев’ю працює як один постійний чат: нові репліки з’являються автоматично, Markdown відображається як форматований текст, а звук нових повідомлень можна ввімкнути кнопкою.

## Початок першої консультації

Достатньо описати:

- якого результату ви хочете;
- що відбувається зараз;
- до якої дати потрібен результат;
- за якою ознакою ви зрозумієте, що мети досягнуто.

Якщо чогось критично бракує, консультант поставить одне конкретне запитання.
