# Журнали консиліумів

Кожна сесія консиліуму зберігається в окремій папці `YYYY-MM-DD-HHMM-<коротка-назва>`.

Обов’язкові файли:

- `BRIEF.md` — завдання, критерій рішення, склад агентів і дозволені інструменти;
- `CHAT.md` — дослівний журнал усіх фактично надісланих повідомлень між агентами;
- `reports/` — первинні звіти агентів-спеціалістів;
- `SYNTHESIS.md` — окремий підсумок головного консультанта;
- `MANIFEST.md` — статус сесії та SHA-256 закритого `CHAT.md`.

`CHAT.md` ведеться лише додаванням нових повідомлень. Попередній текст не виправляється й не видаляється. Після закриття сесії файл стає незмінним.

Під час активної сесії цей журнал дослівно відображається у правому прев’ю через один постійний live-сервер. Нові репліки з’являються в уже відкритій сторінці; для кожного повідомлення не створюється новий HTML і не відкривається нова вкладка. Markdown рендериться як нормальний текст, списки й таблиці.

Запуск:

```bash
node scripts/consilium-live-server.mjs consilium/<сесія> --port 4311
```

Статичний генератор залишається лише резервом для архіву.

Шаблони розміщено в `_template/`.
